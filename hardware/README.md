# Hardware documentation sources

Hardware specifications, interfaces, design files, accessories and maintenance
training are part of mo-docs. Website implementation and deployment belong to
developer. `content/hardware-map.json` (at the repository root) selects public
pages and attachment URLs; training is excluded from navigation.

- [Products](products/): product-specific facts and their sources.
- [Accessories](accessories/): accessory records and compatibility evidence.
- [Author workflow and training](training/README.zh-CN.md).
- [Content conventions](CONTENT-CONTRACT.md).
- [Repository contribution and release workflow](../CONTRIBUTING.md).
