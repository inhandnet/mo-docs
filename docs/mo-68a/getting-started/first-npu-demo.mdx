This runs TI's reference models on the board's AI accelerator and reports how
much of each one the accelerator took. It is the quickest way to confirm the
accelerator works end to end before you put your own model on it.

You need compiled artifacts from an x86 PC first — the board runs models, it
does not compile them.
[Set up the toolchain](../application-development/ai/toolchain.mdx) and
[Compile your own model](../application-development/ai/compile-your-own-model.mdx)
cover that side.

## 1. Clone the tools on the board

The image carries the TIDL runtime libraries, not the repository, so the board
needs its own checkout at the tag it reports:

```bash
cat /etc/inhand-release        # read TIDL_TAG

cd /opt
git clone https://github.com/TexasInstruments/edgeai-tidl-tools.git
cd edgeai-tidl-tools
git checkout <TIDL_TAG>
```

## 2. Copy the artifacts across

From the PC, where the models were compiled. Both directories live under
`runtimes/examples/`:

```bash
cd ~/edgeai-tidl-tools/runtimes/examples
tar -czf - data/ model-artifacts/ \
  | ssh <user>@<board-ip> \
      "cd /opt/edgeai-tidl-tools/runtimes/examples && tar -xzf -"
```

## 3. Run the reference models

On the board. Inference only — the board cannot compile:

```bash
cd /opt/edgeai-tidl-tools
export SOC=J721S2

cd runtimes/examples/python/basic_example
python3 basic_example.py --config ./config.yaml -r onnxrt   --infer
python3 basic_example.py --config ./config.yaml -r tflitert --infer
python3 basic_example.py --config ./config.yaml -r tvmrt    --infer
```

`config.yaml` holds nine models: five ONNX Runtime, two TensorFlow Lite, two
TVM. Each run writes to `outputs/<model>/offload/frame_<n>/`.

## 4. Read the result

Each model prints how many layers went to the accelerator:

```
Number of subgraphs:1 , 329 nodes delegated out of 329 nodes
```

**Read the node counts, not the exit status.** 0 subgraphs, or far fewer nodes
delegated than the model has, means it ran on the Cortex-A72 — correct output,
much slower.

Timings on this board sit above TI's published figures for several models.
That is a difference from a comparison point, not a defect — see
[Performance & benchmarks](../application-development/ai/benchmarks.mdx) for
the measured
spread and what it means.
