Measured inference times for three detection models on Mo 68A, via C7x-MMA vs
Cortex-A72.

## Inference via C7x-MMA runs in milliseconds

Each model ran twice: one run via the C7x-MMA, the other via the Cortex-A72
cores.

| Model | Input size | Via<br />C7x-MMA (ms) | Via<br />Cortex-A72 (ms) | Speed-up |
|---|---|---|---|---|
| `od-8200` YOLOX-nano-lite | 416 × 416 | **5.13** | 553 | 108× |
| `od-8020` SSD-lite MobileNetV2 | 512 × 512 | **8.43** | 2515 | 298× |
| `od-8220` YOLOX-S-lite | 640 × 640 | **13.21** | 2853 | 216× |

Measurement conditions:

- One Mo 68A with TIDL `11_02_17_00`.
- Each inference time is the mean of 100 calls.
- The Cortex-A72 runs use both cores.
- All-zero input, so the times cover the graph, not detection quality.
- All three models were fully offloaded to the C7x-MMA.

## Reproduce these inference times

Run via the C7x-MMA:

```bash
sudo python3 benchmark-inference-mo68a.py \
  /opt/model_zoo/od-8200_onnxrt_coco_edgeai-mmdet_yolox_nano_lite_416x416_20220214_model_onnx
```

Run via the Cortex-A72 cores:

```bash
sudo python3 benchmark-inference-mo68a.py \
  /opt/model_zoo/od-8200_onnxrt_coco_edgeai-mmdet_yolox_nano_lite_416x416_20220214_model_onnx \
  --cpu
```

## Benchmark your own model

The script benchmarks ONNX models. It reads one directory per model, laid out
like this:

```
my-model/
├── model/
│   └── <your-model>.onnx
└── artifacts/
    ├── allowedNode.txt
    ├── onnxrtMetaData.txt
    ├── subgraph_0_tidl_io_1.bin
    └── subgraph_0_tidl_net.bin
```

[Compile your own model](./compile-your-own-model.mdx) leaves the `.onnx` file
under `data/models/` and the artifacts under
`model-artifacts/<model>/artifacts/`, so copy both into one directory first.

Run via the C7x-MMA:

```bash
sudo python3 benchmark-inference-mo68a.py ~/my-model
```

Run via the Cortex-A72 cores:

```bash
sudo python3 benchmark-inference-mo68a.py ~/my-model --cpu
```

Check the offload line the runtime prints: a partly offloaded model does not
compare with the figures above.
