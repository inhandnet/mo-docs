
Models are compiled for the C7x accelerator on a Linux PC with TI's free [edgeai-tidl-tools](https://github.com/TexasInstruments/edgeai-tidl-tools). No registration and no GPU are required.

## On-board SDK (no cross-compiling)

To run models you already have, you do not need the PC toolchain. The image includes a C/C++ SDK:

| Item | Location |
|---|---|
| Headers | `/usr/include/edgeai/` |
| Libraries and CMake package | `/usr/lib/edgeai/`, `/usr/lib/cmake/EdgeAI/` |
| Example projects | `/usr/share/edgeai-cpp-examples/` |
| Developer guide | `/usr/share/edgeai-cpp-examples/DEV_GUIDE.md` |

```cmake
find_package(EdgeAI REQUIRED)
add_executable(my_infer main.cpp)
target_link_libraries(my_infer PRIVATE EdgeAI::edgeai)
```
