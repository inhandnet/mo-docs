
Mo boards run AI models on TI's **C7x DSP with a Matrix Multiply Accelerator (MMA)** — 2 TOPS on Mo 62A, 8 TOPS (two C7x) on Mo 68A. The CPU stays free for your application.

| Layer | What it does |
|---|---|
| Camera + ISP / VPAC | Captures frames; RAW→RGB, WDR, lens correction, scaling in hardware |
| GStreamer / OpenCV | Moves and pre-processes frames |
| ONNX Runtime or TFLite + TIDL | Runs the model; supported layers go to the C7x, the rest to the CPU |
| Your application | Python or C/C++ post-processing and output |

**Workflow:** train in your usual framework → export ONNX or TFLite → compile with <Link to={`/docs/${props.board}/application-development/ai/toolchain`}>edgeai-tidl-tools</Link> on a PC → copy the compiled model to the board → run with ONNX Runtime / TFLite.

Source repositories (each released independently; this documentation links to their releases):

- [mo-models](https://github.com/inhandnet/mo-models): model catalog, compile scripts, benchmark records, compatibility baseline.
- [mo-tools](https://github.com/inhandnet/mo-tools): toolchain version pins, host setup scripts, board test tool.
- [mo-examples](https://github.com/inhandnet/mo-examples): C/C++ and Python inference examples, demo applications.
- [Mo62A](https://github.com/inhandnet/Mo62A): board support package and OS image.
