Mo boards boot from a microSD card. You write the OS image to the card on your computer, then put the card in the board.

:::warning
Writing the image erases everything on the card.
:::

## 2. Write the image with Armbian Imager

The steps below use Armbian Imager. Other image writers, such as [balenaEtcher](https://etcher.balena.io/), also work.

1. Download and install [Armbian Imager](https://imager.armbian.com/) (choose the version for your operating system: Windows, macOS or Linux).

   <div className="mo-tool-screenshot">

   <picture>
     <source media="(prefers-reduced-motion: reduce)" srcSet={installStill} />
     <img src={installAnimation} alt="Downloading and installing Armbian Imager on Windows" />
   </picture>

   </div>

2. Click **Use Custom Image**, select the downloaded OS image, then click **Open**.

   <div className="mo-tool-screenshot">

   <picture>
     <source media="(prefers-reduced-motion: reduce)" srcSet={customImageStill} />
     <Only board={props.board} is="mo-62a">
       <img src={customImageAnimation} alt="Armbian Imager: click Use Custom Image, select the Mo62A OS image, and click Open" />
     </Only>
     <Only board={props.board} is="mo-68a">
       <img src={customImageStill} alt="Armbian Imager on Windows showing the Use Custom Image button" />
     </Only>
   </picture>

   </div>

3. Insert the microSD card into a card reader and connect the reader to your computer. In **Storage**, select your microSD card. Check the device name and capacity to make sure you choose the correct card.

   <Only board={props.board} is="mo-62a">

   <div className="mo-tool-screenshot">
     <picture>
       <source media="(prefers-reduced-motion: reduce)" srcSet={sdCardStill} />
       <img src={sdCardAnimation} alt="Armbian Imager: select the microSD card and review Confirm Selection" />
     </picture>
   </div>

   </Only>

4. Click **Erase & Flash**. Keep the card reader connected while the image is decompressed, written and verified. When **Flash complete!** appears, click **Done**.

   <Only board={props.board} is="mo-62a">

   <div className="mo-tool-screenshot">
     <picture>
       <source media="(prefers-reduced-motion: reduce)" srcSet={writeCardStill} />
       <img src={writeCardAnimation} alt="Armbian Imager: write and verify the microSD card, then click Done" />
     </picture>
   </div>

   </Only>

5. Remove the card safely.

## 3. Pre-configure the board (Optional)

<Only board={props.board} is="mo-62a">

<section className="mo-preconfigure">

You can set your login details and network settings before the first boot. This is especially useful if you plan to use the board without a monitor or keyboard. If you do not need to pre-configure the board, continue to <Link to="/docs/mo-62a/getting-started/first-boot">First boot</Link>.

:::note
For security, we recommend changing the default username and password before the first boot. Choose a strong, unique password. If you skip this step, change the default password immediately after logging in.
:::

1. Open the microSD card's **BOOT** drive on your computer after writing the image. If you have already ejected the card reader, reconnect it. Do not power on the board yet.

   <div className="mo-tool-screenshot">

   ![Windows File Explorer showing sysconfig.txt selected on the BOOT drive](@site/static/img/getting-started/mo62a-boot-sysconfig-windows.png)

   </div>

2. Open the existing `sysconfig.txt` file in a plain-text editor. The screenshot below shows the original file before any changes.

   <div className="mo-tool-screenshot">

   ![Original Mo62A sysconfig.txt showing the default login and commented-out optional settings](@site/static/img/getting-started/mo62a-sysconfig-default.png)

   </div>

   Change the values you need and remove the leading `#` to enable a commented-out setting. Use `key=value` without quotation marks. Edit existing entries rather than adding duplicates; leave settings you do not need commented out. Replace the default login details shown in the screenshot with your own username and a strong, unique password.

   **Login and hostname**

   Replace the example username, password and hostname with your own values:

   ```ini title="BOOT/sysconfig.txt — login and hostname"
   user_name=alice
   user_password=replace-with-your-own-strong-password
   hostname=mo62a-lab
   ```

   **Wi-Fi (optional)**

   To connect to Wi-Fi on the first boot, also enable these settings. Replace the network name and password with your Wi-Fi credentials, and set `wifi_country` to the two-letter code for the country where you will use the board:

   ```ini title="BOOT/sysconfig.txt — Wi-Fi"
   wifi_ssid=YourNetworkName
   wifi_password=YourWiFiPassword
   wifi_country=US
   ```

   If you use Ethernet with DHCP, no network settings need to be changed in this file. For SSH public keys, a static Ethernet IP address, timezone and other options, see the <Link to="/docs/mo-62a/system-configuration/sysconfig-reference">sysconfig.txt reference</Link>.

3. Save the file as UTF-8 plain text without a BOM, keeping the name `sysconfig.txt` (not `sysconfig.txt.txt`). Safely eject the microSD card, then insert it into Mo62A and follow <Link to="/docs/mo-62a/getting-started/first-boot">First boot</Link> to connect and power on the board.

The firmware processes `sysconfig.txt` automatically on the first boot and then deletes it from the BOOT partition. It is not read on subsequent boots. After logging in, check that your settings have taken effect; the file being deleted does not confirm that every setting was applied successfully.

</section>
