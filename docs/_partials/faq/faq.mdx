## Which AI frameworks and model formats are supported?

TI TIDL provides ONNX Runtime and TFLite integration, but model operators, compiled artifacts and the target runtime must match. A supported format alone does not establish that a model runs correctly. Use the board-specific <Link to={`/docs/${props.board}/application-development/ai`}>AI development</Link> guide and its tested compatibility baseline.

## How should I choose a model or board?

Choose from measured workloads with the required input resolution, accuracy, latency and number of streams. TOPS is a hardware rating, not an application frame-rate guarantee. The Mo62A guides include selected classification, detection and segmentation paths; they do not establish OCR support or validate the same workload on Mo68A.

## Do 40-pin HATs and standard cases fit?

A similar footprint and header do not guarantee mechanical or electrical compatibility. Check connector placement, mounting holes, clearance, signal voltage, pin mapping, power and drivers against the <Link to={`/docs/${props.board}/accessories/hat-compatibility`}>hardware compatibility guide</Link>. On Mo62A, pins 27 and 28 share the camera control bus.

## Does Mo run InHand DeviceLive or IEOS?

The documented Mo OS workflow uses Debian tools and SSH. DeviceLive or IEOS integration is not established by these guides.

## The screen stays blank after boot

Check display power, cable and input selection, then try a key or mouse movement. The inspected Mo62A desktop has DPMS enabled with 600-second timers; screen settings can change between installations. Follow the board-specific <Link to={`/docs/${props.board}/getting-started/first-boot`}>first boot</Link> guide and use the serial console if boot progress is unclear. Do not assume a fixed first-boot duration or an automatic reboot.

## The camera is not detected

Follow the board-specific <Link to={`/docs/${props.board}/application-development/camera-and-video`}>camera guide</Link> to check the boot entry, sensor, media graph and device nodes. Power off before re-seating a ribbon cable. Mo62A's tested IMX219 setup does not validate a different sensor or a Mo68A configuration.

## The board does not boot from the SD card

Check the card and image against <Link to={`/docs/${props.board}/getting-started/preparation`}>Preparation</Link> and <Link to={`/docs/${props.board}/getting-started/install-os`}>Install the OS</Link>. Use the serial console to identify where boot stops; verify power and UART wiring before interpreting a silent console.

## Wi-Fi range is very short (Mo62A)

Check that the external antenna is attached and that the network and band match the <Link to="/docs/mo-62a/mo-os/network">tested network setup</Link>.
