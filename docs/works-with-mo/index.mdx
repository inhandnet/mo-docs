Mo runs standard Debian, so most Linux software works as-is. These guides cover tools that need board-specific setup or have official Mo support.

| Project | What it gives you | Guide location (in each board's docs) | Status |
|---|---|---|---|
| Armbian | Community-maintained Debian / Ubuntu builds | Other systems | Planned |
| Ultralytics YOLO | Train and export YOLO models for Mo | Application development › Partner SDKs | Planned |
| Frigate | NVR with object detection on the NPU | Application deployment › Partner applications | Planned |
| Torizon | Container-based industrial Linux and OTA | Other systems | Planned |
| Zephyr | RTOS on the R5F real-time core | Real-time cores (R5F) | Planned |
| ROS 2 / micro-ROS | Robotics | Application development › Partner SDKs | Planned |
| Edge Impulse, Viam, Mender, Node-RED | ML pipelines, robotics, OTA, flow programming | Application development / Application deployment | Planned |
