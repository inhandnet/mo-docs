Mo runs standard Debian, so most Linux software works as-is. These guides cover tools that need board-specific setup or have official Mo support.

| Project | Status | Guide | What it gives you |
|---|---|---|---|
| Armbian | Planned | Other systems | Community-maintained Debian / Ubuntu builds |
| Ultralytics YOLO | Planned | Partner SDKs | Train and export YOLO models for Mo |
| Frigate | Planned | Partner applications | NVR with object detection on the NPU |
| Torizon | Planned | Other systems | Container-based industrial Linux and OTA |
| Zephyr | Planned | Real-time cores (R5F) | RTOS on the R5F real-time core |
| ROS 2 / micro-ROS | Planned | Partner SDKs | Robotics |
| Node-RED | Tested on Mo62A | Partner applications | Flow-based automation and dashboards |
| Edge Impulse, Viam, Mender | Planned | Partner SDKs / applications | ML pipelines, robotics, OTA |
