## 40-pin header (J9)

The header uses **3.3 V logic**. Do not connect 5 V signals to GPIO pins. Mechanically it matches Raspberry Pi HATs; check each HAT's voltage requirements before you connect it.

All signal pins are GPIO by default. Pins 27 and 28 are reserved for the camera I²C bus and cannot be used as GPIO.

`gpiochip0` = MCU domain GPIO, `gpiochip1` = `main_gpio0` (GPIO0_x), `gpiochip2` = `main_gpio1` (GPIO1_x).

### GPIO from the command line

The image ships with libgpiod v2. The `-c` option selects the chip.

```bash
gpiodetect                                 # list GPIO chips
gpioget -c gpiochip2 23                    # read pin 11
gpioset --hold-period=2s -c gpiochip1 39=1 # drive pin 7 high for 2 s
gpiomon -c gpiochip2 23                    # watch edges on pin 11
```

### Peripheral mode: I²C, UART, SPI, PWM, I²S

To use the alternate functions, choose the **`microSD-periph`** entry in the U-Boot boot menu, or set `default microSD-periph` in `/boot/extlinux/extlinux.conf` (BOOT partition). This loads the `k3-am62a7-mo-62a-exp-periph.dtbo` overlay.

| Interface | Pins | Linux device |
|---|---|---|
| I²C (WKUP_I2C0) | 3 (SDA), 5 (SCL) | `/dev/i2c-0` |
| UART5 | 8 (TXD), 10 (RXD) | `/dev/ttyS3` |
| SPI0 | 19 (MOSI), 21 (MISO), 23 (CLK), 24 (CS0), 26 (CS1) | `/sys/bus/spi/devices/spi0.*` (no `spidev` node by default) |
| PWM (EHRPWM0) | 33 (A), 32 (B) | `/sys/class/pwm/pwmchip0/pwm0`, `pwm1` |
| I²S (MCASP2) | 12, 35, 38, 40 | No sound card bound by default |

In peripheral mode the I²C bus numbers shift: `i2c-0` = header pins 3/5, `i2c-3` = camera bus.

## Camera (JP1)

22-pin, 0.5 mm FPC connector with the Raspberry Pi camera pinout, 4-lane MIPI CSI-2. The Sony IMX219 is supported out of the box; see [Display, video & camera](../application-development/camera-and-video.mdx).

## Fan (J6)

4-pin SH1.0 connector for a 5 V PWM fan, with tachometer feedback.

## Debug UART (J4)

3-pin SH1.0 connector. 115200 baud, 8N1. The kernel console is `ttyS2`.

| Pin | Signal |
|---|---|
| 1 | UART0_RXD |
| 2 | GND |
| 3 | UART0_TXD |

## Other connectors

| Connector | Details |
|---|---|
| Power | USB Type-C, 5 V |
| Ethernet | Gigabit (TI DP83867 PHY) |
| USB | 4 × USB 2.0 Type-A through a USB2514 hub |
| Display | micro HDMI (SiI9022A RGB-to-HDMI transmitter) |
| Audio | 3.5 mm headset jack (TLV320AIC3106 codec) |
| Wi-Fi / BT antenna | U.FL connector |
| RTC battery | CR1220 coin cell holder |
