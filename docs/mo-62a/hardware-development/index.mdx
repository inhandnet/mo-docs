Start with specifications, then check physical pins, power and cooling before connecting hardware. This section includes live read-only hardware captures, verified schematic files and the original dimension drawing.

The pages distinguish product ratings and design references from electrical tests. The [Mechanical](./mechanical.mdx) page provides the assembly STEP model, checksum verification and CAD views. The model is a nominal reference, and the datasheet dimension drawing is not approved for production use. A formal hardware change list is still needed for revision-dependent integration.
