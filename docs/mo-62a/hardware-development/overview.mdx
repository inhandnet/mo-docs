Mo62A is built on the TI AM62A74 vision processor, with four Arm Cortex-A53 cores at up to 1.4 GHz and a C7x DSP with Matrix Multiply Accelerator rated at 2 TOPS. These are product specifications, not application benchmark results. See [AI benchmarks](../application-development/ai/benchmarks.mdx) for measured inference times and [Real-time cores](../real-time-cores/overview.mdx) for the actual remote-processor ownership.

## Design reference and validation scope

The original block diagram below is sheet 1 of the published V1.1-named schematic. It is a design reference, not a checklist of enabled or validated features. Its `RJ45+PoE` label refers to the PoE header J5, which passes the Ethernet transformer taps to a PoE HAT; the board itself has no PoE power circuit. The older V1.0-named file also shows an optional eMMC block; that is not evidence of an installed device. The tested system boots from microSD.

| Area | Evidence available | Boundary |
|---|---|---|
| Linux system | [First boot](../getting-started/first-boot.mdx) and [system information](../mo-os/using-mo-os.mdx) | Results apply to the documented image and development board |
| AI inference | [Python/C++ APIs](../application-development/ai/inference-apis.mdx), sample models and measured runs | A 2 TOPS rating is not model FPS |
| Camera | [IMX219 JPEG capture](../application-development/camera-and-video.mdx) | CPU JPEG encode after TI ISP; hardware encode not qualified |
| Expansion | [GPIO, UART5 and PWM loopbacks](../application-development/gpio-and-peripherals.mdx) | No blanket HAT, SPI or external I²C certification |
| Power and cooling | Product ratings and [read-only sensor capture](./power-and-thermal.mdx) | No measured 25 W draw or environmental qualification |
| Secure boot and custom RTOS | SoC/SDK capabilities and preparation guidance | No board key provisioning or custom RTOS application validated |

Memory capacity is an ordered hardware option; the 2/4/8 GB choices do not mean every board has 8 GB. Confirm the purchased SKU and use `free -h` to inspect memory visible to Linux; reservations mean this is not a direct reading of fitted DRAM capacity.
