Use this section for source-build preparation, serial-console access and read-only low-level inspection. The pages distinguish checked source/CLI behaviour from an unperformed fresh-image build, and OP-TEE initialization from validated production secure boot.

Yocto support and production provisioning still need board-specific validation. Internal factory tools are separated from the customer diagnostics linked here; no OTP, EEPROM identity or destructive storage operation is part of the documentation tests.
