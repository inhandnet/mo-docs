Besides the four Cortex-A53 cores running Linux, the AM62A SoC on Mo62A has a C7x DSP and two Cortex-R5F cores. One of them, the MCU R5F, is available for your own FreeRTOS or bare-metal firmware. Linux loads that firmware with remoteproc and exchanges messages with it over RPMsg.

This section follows the TI [MCU+ SDK for AM62Ax 11.01.00.16 user guide](https://software-dl.ti.com/mcu-plus-sdk/esd/AM62AX/11_01_00_16/exports/docs/api_guide_am62ax/index.html) and shows each step on a Mo62A running image V1.1.0:

1. [Overview](./overview.mdx): which core you can use, which cores belong to the system, and the shared memory layout.
2. [SDK setup](./sdk-setup.mdx): install the MCU+ SDK, compiler and SysConfig on an x86 Linux host.
3. [Build and run firmware](./getting-started.mdx): rebuild the TI IPC echo firmware, load it on the MCU R5F and read its log.
4. [Linux communication (RPMsg)](./rpmsg.mdx): exchange messages from a Linux program and measure the round trip.
5. [MCU console](./mcu-console.mdx): your own FreeRTOS code on the MCU R5F, used from SSH or the desktop terminal.
6. [Recovery, known issues and status](./examples.mdx): restore the original firmware, avoid a TI example hang, troubleshoot, and see what has been tested.

:::info[What you need]
An x86-64 Linux host (TI lists Ubuntu 22.04 or later), SSH or desktop access to the board, and `sudo` on the board. No JTAG probe is required for this section; CCS debugging follows the TI guide and is not covered here.
:::
