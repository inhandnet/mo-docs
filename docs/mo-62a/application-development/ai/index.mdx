Build a complete model-to-application workflow on Mo62A: install a fixed x86 toolchain, download a new TI YOLOX-tiny-lite model, calibrate/compile it, compare host and board outputs, then run a warehouse zone-occupancy application with JSON/CSV events and a recorded result video.

The [three-part walkthrough starts here](./toolchain.mdx). It includes downloadable source and licensed inputs, actual compilation/target screenshots and repeated full-video results. This model is not included in the tested image's demo inventory. Its existing person class needs no activation replacement or retraining; new classes require their own training and validation.

The example is an illustrative offline application, not a safety-certified system or a customer case study. This section distinguishes TI's AM62A documentation, version-specific E2E guidance and local Mo62A results. Concept diagrams are not measured traces. TVM, LLMs and arbitrary custom-model exports remain explicitly unvalidated.
