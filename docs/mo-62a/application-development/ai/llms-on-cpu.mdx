Check your own system without installing anything:

```bash
command -v llama-cli
free -h
uname -m
```

`free` reports Linux-visible memory, not the board's fitted DRAM capacity. Reserved firmware memory and current applications affect what is available. The screenshot's 1.3 GiB total and 826 MiB available describe that moment, not a guaranteed budget. Swap is not equivalent to RAM for inference performance.

## Plan an experiment

The upstream [llama.cpp build guide](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md) describes its CPU build. It is an upstream starting point, not a Mo62A-tested installation recipe.

Before selecting a model, account for weights, context/KV cache, runtime buffers and the rest of the OS. Record the exact model revision, quantization, license and required memory; a compressed download size alone does not establish the running memory requirement.

| Check | Record |
|---|---|
| Runtime | Exact source commit and build options |
| Model | Source, revision, checksum, license and quantization |
| Memory | Available memory before loading, peak use and swap activity |
| Workload | Prompt, context size, batch/thread settings and generated-token limit |
| Timing | Model load, prompt processing and token generation separately |
| Stability | Repeated runs, temperature, frequency and out-of-memory events |

Run any first experiment locally with bounded input and output lengths. Do not expose an unauthenticated model server on the network as part of a basic smoke test. Confirm normal system operation afterward.

## Accelerator boundary

The vision examples in this section use TIDL and compiled model artifacts. That does not demonstrate that llama.cpp, a GGUF file or an arbitrary transformer graph can use the C7x accelerator. CPU inference and a TIDL model deployment are different integration paths.

For currently verified AI functionality, start with [Pre-compiled models](./model-hub.mdx) and [Inference APIs](./inference-apis.mdx). A future LLM result needs the complete configuration and raw measurements above before it can be added to the benchmark table.
